智能排座系统使用说明

适用版本 v1.2.0 · 数据保存在浏览器本地 · 无需安装、无需注册
本系统面向中小学班主任与任课教师，用加权评分算法自动完成教室座位安排：视力、身高、成绩、行为、性别等 10 条规则可自由调配权重，支持好友同桌、黑名单隔离、定期轮换与多方案对比，结果量化打分、可导出 Excel 与图片。

一、三步上手

  1. 准备学生名单：点击右栏「🎲 演示数据」生成随机学生体验；正式使用时通过「⋯ 更多 → 📥 导入」导入真实名单——支持 Excel / CSV（中英文表头自动识别、列映射预览、可下载模板），覆盖姓名、性别、身高、视力、成绩、性格、特长、职务、标注 9 个字段。
  2. 设置规则与教室：左栏 ⚖️ 拖动滑块调节 10 条规则的权重（0 为停用）与前排区比例；教室布局在「⋯ 更多 → ⚙️ 设置」中选择——内置标准（7 排×8 座）、小班（5 排×6 座）、大班（9 排×10 座）三套快速模板，也可自定义排数、每排座位数与过道位置。
  3. 一键排座：顶栏「🎯 智能排座」立即生成方案；或选「生成候选方案」一次产出多个方案对比择优。

三、手动微调

  • 拖拽入座：从右栏学生列表拖到座位上；拖学生卡可在座位间交换
  • 点击交换：先点一个已占座位，再点另一个即可交换
  • 双击编辑：双击座位卡或学生项，打开学生资料编辑
  • 撤销重做：Ctrl+Z / Ctrl+Y，排座、交换、导入、轮换全部可撤销

四、座位卡图例

  • 底部图标：👓 近视（优先前排）、🔻 矮个 / 🔺 高个、🌀 调皮（靠前管理）
  • 锁定标识：卡片左上角 🔒 且座位边框变橙色，排座与轮换时该座位保持不动
  • 右上角标签：职务（悬停查看全部）
  • 左侧色条：红=重点关注、橙=需要注意、黄=一般关注、绿=表现良好、紫=特殊情况
  • 边框底色：蓝框淡蓝底=男生，粉框淡粉底=女生

五、常见问题

1. 数据存在哪里？换电脑怎么办？

数据保存在当前浏览器的本地存储（localStorage），不上传任何服务器，改动会自动保存（Ctrl+S 可立即保存）。换电脑或换浏览器前，请用「⋯ 更多 → 📤 导出 → JSON 备份」保存文件，在新设备「⋯ 更多 → 📥 导入 → JSON 备份恢复」。

2. 为什么有的好友没有同桌？

一个座位只有一位同桌，因此一名学生只能有一条好友约束；如需更换请先删除原配对。系统在添加时会自动拦截冲突组合。

3. 前排区比例是什么？

前排区 = 排数 × 前排比例，是「视力保护 / 行为管理 / 前排优先」三条规则共用的优先区域。默认 30%，可按班级情况在左栏调节。

4. 排座结果不满意怎么办？

查看评分报告定位短板维度（如身高有序度低），调高对应规则权重后重新排座；或使用「生成候选方案」对比多个方案择优。手动微调后评分徽章会实时更新。
